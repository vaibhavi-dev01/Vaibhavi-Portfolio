## 🌐 How to Deploy for Free

### Option 1: Deploy to GitHub Pages (Recommended)
1. Initialize Git in this directory (if not already):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Vaibhavi Patil portfolio website"
   ```
2. Create a new repository on your GitHub account (`https://github.com/vaibhavi-dev01/portfolio`).
3. Connect and push your code:
   ```bash
   git remote add origin https://github.com/vaibhavi-dev01/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, go to your repository **Settings** → **Pages** → under **Branch**, choose `main` and `/ (root)` → Click **Save**.
5. Your website will be live at `https://vaibhavi-dev01.github.io/portfolio/`!

---

### Option 2: Deploy to Vercel (Instant 1-Click)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** and import your portfolio repository.
3. Click **"Deploy"** — your portfolio is live in under 30 seconds with a free `.vercel.app` domain and free SSL!
